# Model Diagnostics for Hierarchical Bayesian Coral Bleaching Models

## Overview

This directory contains diagnostic and model-comparison scripts for evaluating the hierarchical Bayesian coral bleaching models fitted in the HPC workflow.

The scripts are designed to:

- compare candidate models using PSIS-LOO cross-validation
- evaluate predictive performance
- assess MCMC convergence
- inspect posterior sampling diagnostics
- generate posterior predictive checks and diagnostic plots

This directory is intended to operate downstream of the HPC model-fitting workflow. It assumes that fitted model objects and precomputed LOO objects already exist in the corresponding `02_model_fitting/hpc/output/` directories.

---

## Scientific Context

The diagnostic workflows evaluate cumulative ordinal Bayesian models implemented with `brms`.

The analyses focus on:

- predictive model comparison
- posterior convergence
- sampling quality
- model adequacy
- posterior predictive behaviour

The workflows support both:

- pre-peak bleaching models
- post-peak bleaching models

---

## Diagnostic Workflows

### Pre-Peak Model Diagnostics

Main script:

```r
comparison_diagnostic_pre_peak_model.R
```

This script:

1. loads candidate pre-peak PSIS-LOO objects
2. compares predictive performance across candidate models
3. reloads the training dataset
4. applies the shared preprocessing/type-fixing function
5. loads the selected fitted model (`model_3.rds`)
6. evaluates convergence and posterior diagnostics
7. generates posterior predictive checks and visualization outputs

#### Selected Model

```text
model_3.rds
```

This model was selected following model comparison procedures described in the associated manuscript currently under submission.


- fitted model `.rds` objects
